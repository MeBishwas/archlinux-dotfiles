# Arch Linux Dotfiles

My personal Arch Linux configuration files.

## Environment

- OS: Arch Linux
- Architecture: x86_64
- Window Manager: i3
- Terminal: Kitty
- Shell: Bash
- Editor: Vim
- Multiplexer: tmux
- Display Manager: SDDM

## Repository Structure

```text
dotfiles/
├── bash/
├── vim/
├── kitty/
├── tmux/
├── i3/
├── rofi/
├── git/
└── scripts/
```

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/archlinux-dotfiles.git ~/dotfiles
```
